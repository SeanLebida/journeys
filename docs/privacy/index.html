Privacy Policy

Last updated: October 12, 2026

Journeys collects no personal data.

The application is completely client-side, privacy-first, and designed to function fully offline without requiring an account, sign-in, or internet connection.

1. No User Accounts or Authentication

Journeys does not require, request, or create any user account. We do not ask for or collect your name, email address, phone number, location, or any personal device identifiers.

2. No Analytics, Tracking, or Advertising

The application contains zero analytics SDKs, zero advertising frameworks, and zero third-party tracking scripts. We do not profile your usage, track your reading habits, or monitor your navigation between biblical sites and routes.

3. Local On-Device Data Storage

All core educational content — including interactive maps, historical journey routes, archaeological notes, and complete Bible texts (KJV & ASV) — is bundled directly in the application binary and read locally from an on-device SQLite database.

Any data generated through your use of the app is stored strictly on your device:

  • Preferences: Theme choices and Bible translation preferences are saved locally in system preferences (UserDefaults on iOS via Capacitor Preferences, or browser localStorage on web).
  • Personal Study Notes & Highlights: Your reading notes and verse highlights are keyed to biblical chapter and verse and stored exclusively on your device. They are never transmitted over the network or synced to any remote server.
  • Quiz Progress: Educational quiz scores and completion states remain strictly local.

4. Transparent & Optional Network Access

The core application requires no internet connection. Network communication only occurs if you explicitly choose to interact with optional online features:

  • Optional Online Map Layers: When you enable satellite imagery or historical Roman Empire map overlays in the map layer panel, tiles are fetched directly from Esri or DARE. These requests transmit standard tile coordinate parameters and never transmit personal information.
  • Optional Street-Level Imagery: Tapping "Street-level imagery" on a site card loads an optional Mapillary viewer for that specific geographic location.
  • Optional Video Links: Tapping "Play video" on an archaeological find loads that single video via YouTube's privacy-hardened youtube-nocookie.com domain.
  • Source Citations: Tapping a reference citation link opens the primary scholarly source in your external system web browser.
  • Optional Content Updates: If an over-the-air content pack is published, checking for updates queries the project repository for public JSON bundle updates.

None of these services are contacted unless you actively initiate the request.

5. Data Retention and Deletion

Because Journeys transmits and stores no user data on servers, there is no personal data held on any server to delete, sell, or disclose.

If you wish to delete all locally stored preferences, notes, and quiz history, you can simply delete the app from your device (or clear site storage if using the web version). Doing so permanently erases all on-device data.

6. App Store & Platform Privacy Declarations

  • Apple App Store: "Data Not Collected". The bundled Apple Privacy Manifest (PrivacyInfo.xcprivacy) declares only standard local UserDefaults storage (Reason CA92.1) for device preferences.
  • Google Play Store: "No data collected; No data shared".
