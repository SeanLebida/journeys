# Alpha 0.3.21

## What changed

- `package.json` and `package-lock.json` are 0.3.21.
- `CHANGELOG.md` has a `## [0.3.21] - 2026-11-07` section for the offline map.
- `src/release/whatsNew.ts` leads with that change. Each step stays within 140 characters.

## Why it mattered

- Play closed testing already has 0.3.20. The next alpha has to be a newer version name, and the Play workflow reads the top changelog section as the release notes.

## Gotchas / pitfalls

- `android/app/build.gradle` stays at versionName 0.3.14 in git. `android-aab.yml` runs `android:version:bump`, which copies `package.json` into versionName and sets versionCode from the commit count.
- `development` was still on 0.3.14 before this release commit. The bump is based on `production`.

## Verification

- `npm test`, `npm run typecheck`, `npm run lint`, and `npm run android:release:notes` in this worktree.
